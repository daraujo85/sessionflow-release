# Voice MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a low-latency voice conversation channel to the SessionFlow Angular app (mic → STT → route into SessionFlow → agent → incremental TTS → speaker), following the MVP staged order defined in the spec.

**Architecture:** A new `voice-gateway` FastAPI WebSocket (`/ws/voice`) terminates the browser connection, talks to two new standalone processes (`stt` = faster-whisper, `tts` = Piper, both persistent/pre-loaded) over local gRPC/HTTP, and reuses two pieces of EXISTING SessionFlow plumbing instead of reinventing them:

- **Routing text into a session** — the existing `publish_command(type="input")` path (`api/app/publishers/command_publisher.py` → RabbitMQ → `worker/sessionflow_worker/command_consumer.py`, already handles `"input"`). No new injection path into tmux.
- **Reading the agent's incremental reply** — the existing per-line output pipeline (`worker/sessionflow_worker/output_capture.py` → `session_output` collection → `sessionflow.events` → `api/app/events_broker.py`). This already *is* `session.response.delta` (spec §11); no new plumbing needed to get agent text out, just a consumer that turns lines into TTS chunks.

**Deviation from spec §2/§17 (documented, not accidental):** the spec assumes STT/TTS live next to the gateway. In this codebase, Whisper/Piper already exist, but bound to the per-host **Worker** (`worker/sessionflow_worker/transcriber.py`, `jarvis.py`), which has no existing low-latency channel to the API (only RabbitMQ pub/sub — explicitly wrong shape for raw PCM per spec §2). Rather than build a new cross-host binary channel, the MVP stands up **new, standalone `stt`/`tts` services** (spec §17, own docker-compose entries) independent of the per-host JARVIS Piper/Whisper. Simpler, no multi-host routing problem, matches the spec verbatim. JARVIS's existing batch voice-note flow (`command_consumer._handle_audio`) is untouched.

**Tech Stack:** FastAPI (WebSocket), `faster-whisper` (STT), Piper CLI (TTS), Angular `AudioWorklet`, existing RabbitMQ/Mongo (`aio_pika`, `motor`).

**Spec:** `docs/superpowers/specs/2026-09-02-voice-mvp.md`

## Global Constraints

- Hot path never touches RabbitMQ/Mongo/SSE for audio frames (spec §2, §4) — only JSON control + binary PCM over the one WebSocket.
- `transcript.partial` never triggers an action; only `transcript.final` does (spec §9 "Regra").
- Sentence chunk boundary for TTS: end-of-sentence punctuation (`. ! ? :`) OR buffer ≥ 100 chars OR ~350ms with no new text and stable content (spec §12).
- `speech_text` (sent to Piper) strips markdown/code blocks/URLs/stack traces/tables (spec §12) — `display_text` (shown on screen) stays full.
- Half-duplex only for this MVP: mic ignored while `SPEAKING`, 250–400ms cooldown after TTS ends before re-opening `LISTENING` (spec §14). No barge-in (spec §15, explicitly out of scope).
- Every turn carries `turnId`; a new `turnId` invalidates everything in-flight for the previous one — pending STT, agent request, TTS queue, browser playback (spec §19).
- WS auth via short-lived single-use ticket (`POST /api/voice/ticket`, TTL 30–60s), never a JWT in the URL (spec §20).
- Out of scope for this plan (spec §27): wake word, full-duplex, barge-in, WebRTC P2P, WebTransport, voice cloning, avatar/lip-sync.

```python
"""Single-use, short-TTL tickets for authenticating `GET /ws/voice`.

WebSockets can't send an Authorization header from the browser, and a long
JWT in the URL leaks into logs/proxies (spec §20). Flow: the already-
authenticated Angular app calls `POST /api/voice/ticket`, gets a random
one-shot token, and opens `wss://.../ws/voice?ticket=...`. The gateway
consumes (and invalidates) it on connect.

Storage is an in-process dict on `app.state.voice_tickets` — tickets live
seconds, a single api replica is assumed for this MVP (same assumption as
`events_broker`'s in-process fan-out).
"""

from __future__ import annotations

import secrets
import time

TicketStore = dict[str, tuple[str, float]]  # ticket -> (user_id, expires_at)

def new_ticket(store: TicketStore, *, user_id: str, ttl_seconds: float = 45.0) -> str:
    ticket = secrets.token_urlsafe(24)
    store[ticket] = (user_id, time.monotonic() + ttl_seconds)
    return ticket

def consume_ticket(store: TicketStore, ticket: str | None) -> str | None:
    """Returns the owning `user_id` and deletes the ticket, or `None` if
    missing/expired/already used."""
    if not ticket:
        return None
    entry = store.pop(ticket, None)
    if entry is None:
        return None
    user_id, expires_at = entry
    if time.monotonic() >= expires_at:
        return None
    return user_id
```

```python
Etapa 1 of the Voice MVP (spec §28): the WebSocket does nothing but echo the
raw PCM back, to validate transport + browser playback before wiring VAD/STT/
TTS. Later tasks replace the echo body with the turn state machine.

from fastapi import APIRouter, Request, WebSocket, WebSocketDisconnect

from app.voice.ticket import consume_ticket, new_ticket

router = APIRouter(tags=["voice"])

@router.post("/api/voice/ticket")
async def issue_voice_ticket(request: Request) -> dict:
    user = request.state.user  # set by the existing auth middleware (app.main)
    ticket = new_ticket(request.app.state.voice_tickets, user_id=user["id"])
    return {"ticket": ticket, "ttl_seconds": 45}

@router.websocket("/ws/voice")
async def voice_ws(websocket: WebSocket) -> None:
    ticket = websocket.query_params.get("ticket")
    user_id = consume_ticket(websocket.app.state.voice_tickets, ticket)
    if user_id is None:
        await websocket.close(code=4401)  # policy violation, custom code
        return
    await websocket.accept()
    try:
        while True:
            frame = await websocket.receive_bytes()
            await websocket.send_bytes(frame)  # Etapa 1: pure echo
    except WebSocketDisconnect:
        pass
```

```javascript
// frontend/src/app/core/voice/worklets/capture.worklet.js
class CaptureProcessor extends AudioWorkletProcessor {
  constructor() {
    super();
    this._frameSamples = 320; // 20ms @ 16kHz
    this._buffer = new Float32Array(0);
    this._inRate = sampleRate; // AudioWorkletGlobalScope, actual device rate
  }

  _resampleTo16k(input) {
    if (this._inRate === 16000) return input;
    const ratio = this._inRate / 16000;
    const outLength = Math.floor(input.length / ratio);
    const out = new Float32Array(outLength);
    for (let i = 0; i < outLength; i++) {
      out[i] = input[Math.floor(i * ratio)];
    }
    return out;
  }

  process(inputs) {
    const channel = inputs[0][0];
    if (!channel) return true;
    const resampled = this._resampleTo16k(channel);
    const merged = new Float32Array(this._buffer.length + resampled.length);
    merged.set(this._buffer);
    merged.set(resampled, this._buffer.length);
    this._buffer = merged;

    while (this._buffer.length >= this._frameSamples) {
      const frame = this._buffer.subarray(0, this._frameSamples);
      const pcm16 = new Int16Array(this._frameSamples);
      for (let i = 0; i < this._frameSamples; i++) {
        const s = Math.max(-1, Math.min(1, frame[i]));
        pcm16[i] = s < 0 ? s * 0x8000 : s * 0x7fff;
      }
      this.port.postMessage(pcm16.buffer, [pcm16.buffer]);
      this._buffer = this._buffer.subarray(this._frameSamples);
    }
    return true;
  }
}
registerProcessor('capture-processor', CaptureProcessor);
```

```javascript
// frontend/src/app/core/voice/worklets/playback.worklet.js
class PlaybackProcessor extends AudioWorkletProcessor {
  constructor() {
    super();
    this._queue = [];
    this._offset = 0;
    this.port.onmessage = (ev) => {
      if (ev.data === 'clear') {
        this._queue = [];
        this._offset = 0;
        return;
      }
      this._queue.push(new Int16Array(ev.data));
    };
  }

  process(_inputs, outputs) {
    const out = outputs[0][0];
    for (let i = 0; i < out.length; i++) {
      if (this._queue.length === 0) {
        out[i] = 0;
        continue;
      }
      const current = this._queue[0];
      out[i] = current[this._offset] / 0x8000;
      this._offset++;
      if (this._offset >= current.length) {
        this._queue.shift();
        this._offset = 0;
      }
    }
    return true;
  }
}
registerProcessor('playback-processor', PlaybackProcessor);
```

```typescript
// frontend/src/app/core/voice/voice-socket.service.ts
import { Injectable } from '@angular/core';
import { Subject } from 'rxjs';
import { VoiceServerMessage } from './voice-state';

@Injectable({ providedIn: 'root' })
export class VoiceSocketService {
  private ws: WebSocket | null = null;
  readonly messages$ = new Subject<VoiceServerMessage>();
  readonly binary$ = new Subject<ArrayBuffer>();
  readonly closed$ = new Subject<void>();

  connect(ticket: string, origin = location.origin): void {
    const wsUrl = origin.replace(/^http/, 'ws') + `/ws/voice?ticket=${ticket}`;
    this.ws = new WebSocket(wsUrl);
    this.ws.binaryType = 'arraybuffer';
    this.ws.onmessage = (ev) => {
      if (typeof ev.data === 'string') {
        this.messages$.next(JSON.parse(ev.data));
      } else {
        this.binary$.next(ev.data as ArrayBuffer);
      }
    };
    this.ws.onclose = () => this.closed$.next();
  }

  sendJson(msg: Record<string, unknown>): void {
    this.ws?.send(JSON.stringify(msg));
  }

  sendPcmFrame(frame: ArrayBuffer): void {
    if (this.ws?.readyState === WebSocket.OPEN) this.ws.send(frame);
  }

  disconnect(): void {
    this.ws?.close();
    this.ws = null;
  }
}
```

```typescript
import { Injectable } from '@angular/core';

@Injectable({ providedIn: 'root' })
export class MicrophoneService {
  private ctx: AudioContext | null = null;
  private node: AudioWorkletNode | null = null;
  private stream: MediaStream | null = null;
  private muted = false;

  async start(onFrame: (pcm16: ArrayBuffer) => void): Promise<void> {
    this.stream = await navigator.mediaDevices.getUserMedia({
      audio: { echoCancellation: true, noiseSuppression: true, autoGainControl: true, channelCount: 1 },
    });
    this.ctx = new AudioContext();
    await this.ctx.audioWorklet.addModule('core/voice/worklets/capture.worklet.js');
    const source = this.ctx.createMediaStreamSource(this.stream);
    this.node = new AudioWorkletNode(this.ctx, 'capture-processor');
    this.node.port.onmessage = (ev) => {
      if (!this.muted) onFrame(ev.data as ArrayBuffer);
    };
    source.connect(this.node);
  }

  /** spec §14: ignore mic frames while SPEAKING, without tearing down the graph. */
  setMuted(muted: boolean): void {
    this.muted = muted;
  }

  stop(): void {
    this.node?.port.close();
    this.stream?.getTracks().forEach((t) => t.stop());
    this.ctx?.close();
    this.node = null;
    this.stream = null;
    this.ctx = null;
  }
}
```

```python
"""Pure endpointing state machine — decoupled from the actual VAD model so it
is unit-testable without audio (spec §8).

The caller feeds one `is_speech` bool per fixed-size frame (20ms, matching the
capture worklet's frame size) from whatever VAD decides voice activity
(webrtcvad/Silero). This class only tracks the "speech / silence run" timing
and emits the two events the turn manager cares about.
"""

from __future__ import annotations

from typing import Literal

EndpointEvent = Literal["speech_start", "utterance_end"]

class Endpointer:
    def __init__(self, *, silence_ms_to_end: int = 450, frame_ms: int = 20) -> None:
        self._silence_frames_to_end = max(1, round(silence_ms_to_end / frame_ms))
        self._in_speech = False
        self._silence_run = 0

    def feed(self, *, is_speech: bool) -> EndpointEvent | None:
        if is_speech:
            self._silence_run = 0
            if not self._in_speech:
                self._in_speech = True
                return "speech_start"
            return None
        if not self._in_speech:
            return None
        self._silence_run += 1
        if self._silence_run >= self._silence_frames_to_end:
            self._in_speech = False
            self._silence_run = 0
            return "utterance_end"
        return None

    def reset(self) -> None:
        self._in_speech = False
        self._silence_run = 0
```

```python
"""Drives one WS connection's turn-taking (spec §7): buffers mic frames,
runs endpointing, and on utterance end calls STT and emits `transcript.final`.

Task 5 extends `_on_utterance` to route the text into a SessionFlow session
and stream the reply; kept here as a stub call for now.
"""

from __future__ import annotations

import uuid
from collections.abc import Awaitable, Callable

from app.voice.vad import Endpointer

class TurnManager:
    def __init__(
        self,
        *,
        send_json: Callable[[dict], None],
        send_binary: Callable[[bytes], None],
        stt_client,
        vad_is_speech: Callable[[bytes, int], bool],
        silence_ms_to_end: int = 450,
        frame_ms: int = 20,
    ) -> None:
        self._send_json = send_json
        self._send_binary = send_binary
        self._stt = stt_client
        self._vad_is_speech = vad_is_speech
        self._endpointer = Endpointer(silence_ms_to_end=silence_ms_to_end, frame_ms=frame_ms)
        self._utterance_buf = bytearray()
        self._turn_id: str | None = None
        self._cancelled_turns: set[str] = set()

    async def handle_frame(self, frame: bytes, *, index: int) -> None:
        is_speech = self._vad_is_speech(frame, index)
        if is_speech:
            self._utterance_buf.extend(frame)
        event = self._endpointer.feed(is_speech=is_speech)
        if event == "speech_start":
            self._turn_id = str(uuid.uuid4())
            self._utterance_buf.clear()
            self._utterance_buf.extend(frame)
        elif event == "utterance_end":
            await self._on_utterance_end()

    async def _on_utterance_end(self) -> None:
        turn_id = self._turn_id
        pcm = bytes(self._utterance_buf)
        self._utterance_buf.clear()
        if turn_id is None or turn_id in self._cancelled_turns:
            return
        text = await self._stt.transcribe(pcm)
        if turn_id in self._cancelled_turns:
            return  # cancelled while transcribing
        self._send_json({"type": "transcript.final", "turnId": turn_id, "text": text})

    async def cancel(self, turn_id: str) -> None:
        self._cancelled_turns.add(turn_id)
```

- [ ] **Step 3: Implement `api/app/voice/speech_formatter.py`**

```python
"""display_text vs speech_text (spec §12): the agent's raw reply is fine to
show on screen, but Piper should never be handed markdown/code/URLs/stack
traces. Also chunks incremental text into short, sentence-shaped pieces so
TTS starts before the full reply exists.
"""

from __future__ import annotations

import re

_CODE_BLOCK_RE = re.compile(r"```.*?```", re.DOTALL)
_INLINE_CODE_RE = re.compile(r"`[^`]*`")
_URL_RE = re.compile(r"https?://\S+")
_SENTENCE_END_RE = re.compile(r"[.!?:]\s*$")

def to_speech_text(display_text: str) -> str:
    text = _CODE_BLOCK_RE.sub(" ", display_text)
    text = _INLINE_CODE_RE.sub(" ", text)
    text = _URL_RE.sub(" ", text)
    return " ".join(text.split())

class SentenceChunker:
    """Accumulates text deltas, yields complete chunks as soon as a sentence
    ends or the buffer crosses `max_chars` (spec §12)."""

    def __init__(self, *, max_chars: int = 100) -> None:
        self._max_chars = max_chars
        self._buf = ""

    def feed(self, text_delta: str) -> list[str]:
        self._buf += text_delta
        chunks: list[str] = []
        while True:
            chunk = self._try_extract()
            if chunk is None:
                break
            chunks.append(chunk)
        return chunks

    def _try_extract(self) -> str | None:
        stripped = self._buf.strip()
        if not stripped:
            return None
        if _SENTENCE_END_RE.search(stripped):
            self._buf = ""
            return stripped
        if len(stripped) >= self._max_chars:
            # break at the last space before the cap so words aren't split
            cut = stripped.rfind(" ", 0, self._max_chars)
            cut = cut if cut > 0 else self._max_chars
            chunk, rest = stripped[:cut].strip(), stripped[cut:].strip()
            self._buf = rest
            return chunk
        return None

    def flush(self) -> str | None:
        stripped = self._buf.strip()
        self._buf = ""
        return stripped or None
```

```python
"""Turns the EXISTING per-line output stream (`output_capture.py` →
`session_output` → `sessionflow.events` → `EventsBroker`) into the
`session.response.delta`/`.end` shape the spec describes (§11) — no new
plumbing between the Worker and the API, just a consumer shaped for voice.
"""

from __future__ import annotations

from collections.abc import Awaitable, Callable

# Statuses meaning "the agent has stopped producing output for this turn" —
# same vocabulary the terminal/session UI already uses for waiting states.
_DONE_STATUSES = {"waiting_input", "waiting_confirmation", "idle"}

async def bridge_agent_output(
    session_id: str,
    broker,
    on_text_delta: Callable[[str], Awaitable[None]],
    on_done: Callable[[], Awaitable[None]],
) -> None:
    queue = await broker.subscribe()
    while True:
        event = await queue.get()
        candidate_session = event.get("session") or event.get("session_id")
        if candidate_session != session_id:
            continue
        if event.get("type") == "session_status" and event.get("status") in _DONE_STATUSES:
            await on_done()
            return
        text = event.get("text")
        if text:
            await on_text_delta(text)
```

```typescript
// frontend/src/app/core/voice/voice.service.ts
import { Injectable, signal } from '@angular/core';
import { VoiceSocketService } from './voice-socket.service';
import { MicrophoneService } from './microphone.service';
import { AudioPlaybackService } from './audio-playback.service';
import { VoiceState, VoiceServerMessage } from './voice-state';
import { ApiService } from '../api.service'; // existing service issuing authenticated requests

const COOLDOWN_MS = 350;

@Injectable({ providedIn: 'root' })
export class VoiceService {
  readonly state = signal<VoiceState>('idle');
  readonly transcript = signal('');
  readonly reply = signal('');
  private turnId: string | null = null;

  constructor(
    private readonly socket: VoiceSocketService,
    private readonly mic: MicrophoneService,
    private readonly playback: AudioPlaybackService,
    private readonly api: ApiService,
  ) {
    this.socket.messages$.subscribe((msg) => this.onMessage(msg));
    this.socket.binary$.subscribe((buf) => this.playback.enqueue(buf));
  }

  async start(): Promise<void> {
    const { ticket } = await this.api.post<{ ticket: string }>('/api/voice/ticket', {});
    this.socket.connect(ticket);
    await this.playback.init(22050);
    await this.mic.start((frame) => this.socket.sendPcmFrame(frame));
    this.state.set('listening');
  }

  stop(): void {
    this.mic.stop();
    this.playback.close();
    this.socket.disconnect();
    this.state.set('idle');
  }

  bindSession(sessionId: string): void {
    this.socket.sendJson({ type: 'voice.bind_session', sessionId });
  }

  private onMessage(msg: VoiceServerMessage): void {
    switch (msg.type) {
      case 'transcript.final':
        this.turnId = msg.turnId;
        this.transcript.set(msg.text ?? '');
        this.state.set('waiting_agent');
        break;
      case 'assistant.text.delta':
        this.reply.set((this.reply() + (msg.text ?? '')).trim());
        break;
      case 'assistant.speech.start':
        this.onSpeechStart();
        break;
      case 'assistant.speech.end':
        this.onSpeechEnd();
        break;
    }
  }

  private onSpeechStart(): void {
    this.state.set('speaking');
    this.mic.setMuted(true);
  }

  private onSpeechEnd(): void {
    this.state.set('cooldown');
    setTimeout(() => {
      this.mic.setMuted(false);
      this.state.set('listening');
      this.reply.set('');
    }, COOLDOWN_MS);
  }

  cancelCurrentTurn(): void {
    if (this.turnId) {
      this.socket.sendJson({ type: 'voice.cancel', turnId: this.turnId });
      this.playback.clear();
    }
  }
}
```
